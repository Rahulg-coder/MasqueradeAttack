# IEEE Algorithm Map and Novelty Notes

This guide links every pseudocode line in Algorithms 1-3 to the closest Java implementation. A linked Java line may implement the step differently; those differences are called out so the project is not presented as a literal reproduction where it is not.

## Paper novelty and manuscript note

The cited paper combines weighted message-sequence graphs, per-CAN-ID signal means and standard deviations, and pooled Node2Vec embeddings. It compares combined features with graph-only and time-series variants and reports statistical comparisons. This Java project implements the combined Random Forest path for one configured window/stride pair; it does not reproduce every ablation, parameter sweep, XGBoost run, or significance test. Describe the paper's contribution as prior work, cite Marfo et al., and describe this Java implementation's adaptations in your own words.
